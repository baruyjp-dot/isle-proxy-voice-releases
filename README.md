# Isle Proxy Voice

**Voice Utility for The Isle: Evrima**

Isle Proxy Voice is a voice-related utility project designed for use alongside **The Isle: Evrima**. This repository contains release builds and related files for the Isle Proxy Voice application.

## 📌 Features

- 🎙️ Voice-related functionality for The Isle: Evrima
- 🦖 Designed for the dinosaur survival game experience
- 💻 Windows release builds
- 📦 Easy access to downloadable releases

*Features may vary depending on the release version.*

## 📥 Download

1. Open the [Releases](../../releases) page.
2. Select the latest available release.
3. Download the appropriate file under **Assets**.
4. Extract the downloaded archive if necessary.
5. Follow the installation instructions included with the release.

## ⚙️ Installation

1. Download the latest release.
2. Extract the files into a folder of your choice.
3. Run the application executable, if provided.
4. Follow any additional setup instructions for your version.

**Important:** Check the release notes before installing or updating the application.

## 🎮 Compatibility

- **Game:** The Isle: Evrima
- **Platform:** Windows (if supported by the current release)
- **Version compatibility:** Refer to the release notes for supported versions.

## ❓ Troubleshooting

If you encounter any issues:

- Make sure you downloaded the correct release.
- Check that all required files are extracted.
- Verify that your system meets the application's requirements.
- Restart the application and check whether the issue persists.
- Report reproducible issues with the release version and relevant error messages.
